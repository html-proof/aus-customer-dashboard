Customer access isn't switched on yet

The Shopify app needs the read_customers permission to show this page.
1. Shopify Dev Dashboard → your app → Versions → add read_customers to the access scopes and release.
2. Under API access → Protected customer data, request access (add name, email and address fields to show contact details).
3. Approve the updated permissions in PixMagic's Shopify admin, then press Refresh here.
